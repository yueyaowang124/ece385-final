# Archived Sprite Sources

`source/` contains 11 PNG inputs copied from the course project's Image_to_COE working directory. The files are preserved without modification as source artwork for review.

Final compiled ROM data already lives under `src/coe/` at the repository root. The working directory includes several iterations, so these PNGs should not be assumed to regenerate the exact final ROMs. In particular, the submission archive and final Git commit contain different fish image/palette data.

Keep each existing COE and palette together. Convert experimental copies into a separate output directory and compare the rendered result before updating the hardware assets.

See `tools/image_to_coe/README.md` for the archived conversion workflow.
